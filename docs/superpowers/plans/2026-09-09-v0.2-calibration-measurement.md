# v0.2 Calibration Measurement Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the prototype Calibration input and measurement path with a source-separated, JP-scoped, reproducible real-font pipeline while preserving v0.1 runtime behavior and only integrating profiles that pass per-operator holdout gates.

**Architecture:** Resolver data remains an independent runtime/native-resolution pipeline. Calibration adapters consume source artifacts directly and emit a small normalized `CalibrationSourceRecord`; selection, ambiguity filtering, and character-hash partitioning produce measurement samples. Tools-only fontkit and Skia-backed rasterization generate evidence, loss, optimization, median profiles, and gates; raw evidence stays outside Git and accepted profiles are the only possible runtime output.

**Tech Stack:** TypeScript/Node 22 tooling, Vitest, `fontkit@2.0.4`, `@napi-rs/canvas@1.0.8`, SHA-256, existing parser/layout model, GitHub release font assets.

**Spec:** User-provided “IDS-Composit v0.2 Calibration実測基盤確定・実装指示書”, with the repository v0.2 chapters under `docs/v0.2/` as the maintained implementation record.

## Global Constraints

- Keep `package.json` at `0.2.0-dev.0` until a later release decision.
- Keep `v0.1.0` commit/tag `25e0449` and all v0.1 compatibility behavior unchanged.
- `known-index-v0.2.json` is Resolver input only; it is not Calibration truth.
- Calibration training region is JP only; Sans JP trains, Serif JP cross-validates.
- Do not import `fontkit` or Canvas into `src/runtime`; Canvas/SVG remain under `tools/calibration/`.
- Do not commit font binaries, PNGs, alpha masks, per-character raster/optimization dumps, or temporary corpora.
- Preserve source IDS variants and ambiguity; never semantic-canonicalize or majority-vote them.
- A profile is emitted only per operator after train >= 80, holdout >= 20, Sans gates, and Serif gates pass.
- Runtime may consume only accepted operator median profiles; otherwise it keeps the v0.1 fixed-template fallback.
- Every phase ends with focused tests, full tests, typechecks, relevant builds, Current State/Traceability updates, and a small commit.
